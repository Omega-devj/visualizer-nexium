Overlay OBS

Un visuel sur fond transparent et une carte « en lecture » pour ton stream. Colle l’adresse dans une source Navigateur d’OBS.

Cette adresse contient ta connexion Spotify. Pour l’invalider : spotify.com/account/apps, « Retirer l’accès », puis reconnecte-toi ici.

Dans OBS : Sources, +, Navigateur, colle l’adresse, largeur 1920, hauteur 1080. Les visuels suivent le vrai son quand le morceau joue dans la source (dépôt GitHub) ; avec Spotify, Last.fm ou ListenBrainz ils restent en ambiance et la carte suit ton titre en cours.

Confidentialité et données

Reste sur ton appareil : tes fichiers audio (jamais envoyés), tes réglages, tes presets, tes sources épinglées et, si tu l’as demandé, les identifiants de tes serveurs.

Peut être envoyé : les paroles transmettent le titre, l’artiste et l’album à LRCLIB ; chaque recherche ou lien contacte le service choisi ; le code QR passe par api.qrserver.com et le lien court par is.gd.

Partager le son d’un onglet

  1. Ouvre le service (Spotify, YouTube, SoundCloud, Twitch…) dans un autre onglet et lance un morceau.
  2. Reviens ici et clique « Choisir l’onglet ».
  3. Dans la fenêtre du navigateur, ouvre « Onglet Chrome » et choisis l’onglet du service.
  4. Coche « Partager aussi l’audio de l’onglet », puis Partager.

Les visuels suivent alors le vrai son. Tu peux retourner sur l’autre onglet : le partage continue.

Connecter Spotify

Affiche le titre, la pochette et les couleurs du morceau en cours dans Spotify.

Crée une application sur developer.spotify.com/dashboard, ajoute l’adresse ci-dessus comme « Redirect URI », puis colle le Client ID. Spotify protège son audio : pour animer les visuels avec le vrai son, utilise ensuite « Synchroniser le son » et partage l’onglet Spotify avec son audio.

Spotify peut limiter le nombre d’utilisateurs autorisés pour un Client ID en mode développeur.
